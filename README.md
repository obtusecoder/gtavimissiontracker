# GTA VI Mission Tracker

A single-page checklist of every GTA VI story mission, optional mission and Strangers & Freaks side mission, with progress bars for story and overall completion.

- Tick missions off as you play. Progress is saved in your browser, so each person who visits keeps their own list.
- Filter by story or side missions, hide completed ones, or search by name.
- Each mission is tagged Optional, Missable, Side, or Jason/Lucia-only where it applies.

> **Accuracy:** the list was built from community guides published in GTA VI's launch week (November 2026). Guides disagree on some details, so it may not be 100% accurate. It's checked against the latest guides weekly.

## Hosting

Plain HTML, no build step. To host on GitHub Pages, go to **Settings → Pages**, set the source to the `main` branch and `/ (root)`, and save.
